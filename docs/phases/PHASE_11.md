# Phase 11 — V1 lesson-pack and coupon foundations

The brief lists these as the first post-launch V1 capabilities. This phase
starts after the Phase 10 launch-operations handoff.

## Initial scope

- Lesson packs and coupon data models with ownership and expiry rules.
- Server-side validation and protected student/admin endpoints.
- Pricing calculation seams that preserve integer paise accounting.
- Focused tests before adding client purchase/admin screens.

## Deferred V1 scope

Referral credits, Google Calendar, homework/session notes, embedded whiteboard,
parent accounts, automated payouts, complete Hindi UI, WhatsApp/SMS, Redis
queues, Atlas Search, invoices, verification partners and badges remain later
chunks.
